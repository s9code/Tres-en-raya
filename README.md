# Tic Tac Toe (Tres en Raya)

Proyecto del currículo Full Stack JavaScript de [The Odin Project](https://www.theodinproject.com/).

## 🎯 Objetivo

Construir un juego de tres en raya interactivo en el navegador aplicando:

- Principios de diseño modular (Factory Functions y Module Pattern / IIFE).
- Closures para mantener el estado interno de cada módulo privado, exponiendo solo los métodos necesarios hacia el exterior.
- Separación estricta de responsabilidades (Lógica vs Renderizado DOM).

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
